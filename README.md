# Certificate Studio

**[Download Certificate Studio](https://github.com/jeevanjoy60/Certificate-studio/releases/latest)**

Certificate Studio is a Windows desktop app for creating personalized certificates in bulk using a PDF certificate template and a CSV file.

Built for college clubs, events, workshops, competitions, and organizations.

## Features

* Use your own PDF certificate template
* Import names from a CSV file
* Select the CSV name column
* Add custom TTF/OTF fonts
* Set font size and text color
* Automatically fit long names
* Export as PDF or PNG
* Download all certificates as a ZIP
* Runs locally on your computer

## How to Use

### 1. Install

Download the latest `.exe` installer from the [Releases](../../releases) page and install Certificate Studio.

### 2. Prepare the Certificate

Create your certificate as a PDF and place the Certificate Studio placeholder where the name should appear.

The current placeholder is:

```text
ㅤ
```

### 3. Prepare the CSV

Use a CSV with a name column:

```csv
Name
Jeevan Joy
Arun Kumar
Ananya Thomas
Rahul Nair
```

### 4. Add Files

Open Certificate Studio and upload:

* Certificate PDF
* Student CSV
* Custom font *(optional)*

### 5. Set Options

Choose:

* Font size
* Ink color
* CSV name column
* PDF placeholder
* Output format: PDF / PNG

### 6. Generate

Click **Generate certificates**.

Your personalized certificates will be generated and packaged into a ZIP file.

## Requirements

* Windows 10 or later
* No programming knowledge required

## Privacy

Certificate Studio processes your files locally on your computer. Your certificate templates and CSV data do not need to be uploaded to a server.
